# Motivos de rejeição do Faturei

| Código | O que quer dizer | O que o cliente faz |
|---|---|---|
| R-12 | CFOP de operação dentro do estado numa nota para outro estado | Emitir de novo com o CFOP de operação interestadual |
| R-18 | Destinatário sem inscrição estadual numa operação que exige | Pedir a inscrição ao destinatário ou emitir como consumidor final |
| R-31 | Conta do emissor suspensa | Regularizar o pagamento; a nota é emitida de novo depois da reativação |
| R-40 | Valor total diferente da soma dos itens | Conferir descontos e arredondamento e emitir de novo |
